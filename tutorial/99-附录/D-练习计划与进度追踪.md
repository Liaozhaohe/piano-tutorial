## 1. 50 周周计划模板

**使用方法**

1. 在"起始日期"栏填入每周一的日期。
2. 一周内按 [0-1 §5](../00-导读/0-1-如何使用本教程.md#5-每日练习模板) 的模板执行；**每周练习 ≥ 5 天**，至少留 1 天完全休息。
3. 周末（第 6 或第 7 天）用"本周核心技术指标"做一次验收。**未通过则整周顺延**，不得推进到下一周。
4. 顺延累计超过 3 周时，转入 [0-1 §6](../00-导读/0-1-如何使用本教程.md#6-如何判断自己卡住了) 的停滞诊断流程。

**读法约定**：指标中的"×N 遍无误"一律指**连续** N 遍无错音、无节拍偏移（以节拍器为准）；"双手"指左右手合奏；调名缺省时为 C 大调。

## 3. 160 讲进度追踪表

**列的定义**

| 列 | 含义 |
| --- | --- |
| **讲次** | 第 N 讲 |
| **标题** | 该讲内容 |
| **首次完成日期** | 第一次把该讲内容从头到尾走通一遍的日期（不要求达标） |
| **达标日期** | 通过该讲"达标自检"全部条目的日期 |
| **达标 BPM** | 达标时的节拍器速度（非技术性讲次填 `—`） |
| **备注** | 卡点、错误类型、需要复查的内容 |

> 填写规则：**达标日期**留空即表示该讲未完成，**不得**推进到下一讲（唯一例外见 [0-1 §4.3](../00-导读/0-1-如何使用本教程.md#43-唯一允许的非顺序操作)：第 17–24 讲的听辨训练可并行前置）。

## 4. 12 调掌握度矩阵

> 对应第 74–98 讲。每格填入**达标日期**与**达标 BPM**，格式 `MM/DD@BPM`（例：`06/14@100`）。未达标留空。
> 调的排列顺序为**五度圈上行**（每步 +7 个半音），这也是 [0-1 §6.2 成因 C](../00-导读/0-1-如何使用本教程.md#成因-c只练熟悉调) 处方中的轮转顺序。

### 4.1 六项能力的定义与达标判据

| 能力 | 具体内容 | 达标判据 |
| --- | --- | --- |
| **① 音阶** | 该调自然大调音阶，双手同向 2 个八度，上行 + 下行 | `♩=100`，连续 3 遍无误，不看键盘 |
| **② 正三和弦** | `I – IV – V – I`，原位 + 两种转位，双手 | `♩=80`，连续 3 遍无误 |
| **③ 顺阶七和弦** | `Imaj7 iim7 iiim7 IVmaj7 V7 vim7 viim7b5` 依次连奏，双手 | `♩=60`，连续 3 遍无误，能口述每个和弦的四个音 |
| **④ 1645 走向** | `I – vi – IV – V`，配"二八"`X-X-` 节奏，双手 8 小节 | `♩=100`，连续 3 遍无误 |
| **⑤ 左手大跳** | 根音—五音—八度织体（第 65–66 讲），配 1645 走向 | `♩=90`，连续 3 遍无误，不看左手 |
| **⑥ 完整弹唱** | 在该调上边弹伴奏边唱一段 ≥ 16 小节的旋律 | 全程不中断，伴奏不因演唱而丢拍 |

## 6. 复习制度（间隔重复）

### 6.1 为什么钢琴的运动记忆需要间隔安排

本教程采用**间隔重复**（spaced repetition）安排复习，理由有三：

| # | 依据 | 对钢琴练习的含义 |
| --- | --- | --- |
| 1 | **分布式练习优于集中式练习**（distributed practice > massed practice）。这是运动技能学习中重复验证最稳健的发现之一：总练习量相同时，分散到多天的长期保持率显著高于集中在一天。 | 240 分钟分 6 天 × 40 分钟，效果显著优于 1 天 × 240 分钟。因此本教程规定**每周练习 ≥ 5 天**，并禁止"周末补练"。 |
| 2 | **巩固需要跨越睡眠**（consolidation）。运动序列在首次练习后并不立即稳定，需要经过一段离线时间（其中睡眠期起主要作用）才转为长期记忆。在此期间该记忆是**易受干扰**的。 | 新学的指法在当天练得再多也不会立刻稳定；**次日的第一次复演**才是真正的检验点。因此复习安排中第 1 天（次日）的复习不可省略。 |
| 3 | **提取比重复更有效**（retrieval practice / testing effect）。主动从记忆中"调出"一段内容，比再看一遍谱子重复它更能加固记忆。 | 复习时**必须先凭记忆演奏一遍**，出错后再回看谱子。禁止"一边看谱一边过一遍"式的复习——那是重复，不是提取。 |

> **诚实说明**：具体的 **1 / 3 / 7 / 21 天**间隔是本教程为便于执行而选定的**取整方案**，其依据是上述三条稳健的实验规律，但这四个具体数字**不是**实验测定的最优值。你可以按自己的遗忘情况调整（见 §6.4 的动态规则），但**不得**取消间隔安排本身。

### 6.2 标准复习日程

每学完一讲，该讲进入复习队列，按下表复习：

| 复习轮次 | 距首次学习 | 复习内容 | 时长 | 达标判据 |
| ---: | ---: | --- | ---: | --- |
| R1 | **第 1 天**（次日） | 该讲的主要练习，**先凭记忆演奏 1 遍**，再对照谱子 | 5 min | 凭记忆演奏的错误 ≤ 3 处；对照后连续 3 遍无误 |
| R2 | **第 3 天** | 同上，速度提高 5 BPM | 4 min | 新速度下连续 3 遍无误 |
| R3 | **第 7 天** | 同上，**并迁移到另一个调** | 5 min | 原调 3 遍无误；新调在 −20 BPM 下 3 遍无误 |

| 某轮复习**一次通过**（凭记忆首遍即无误） | 下一轮间隔 **×1.5**（如 R3 从第 7 天推到第 10 天） |
| 某轮复习**首遍错误 > 3 处** | **回退一轮**：该讲重新从 R1 开始计数 |
| 某轮复习**完全想不起来** | 视为未学：重做该讲的完整练习流程，重置复习队列 |
| 连续 3 讲都发生回退 | 停止推进新讲次，转入 [0-1 §6](../00-导读/0-1-如何使用本教程.md#6-如何判断自己卡住了) 的停滞诊断 |
| 中断练习 > 7 天 | 全部复习队列重置为 R1；按 [0-1 §8 Q14](../00-导读/0-1-如何使用本教程.md#q14多长时间没练会退步退步后怎么恢复) 的表确定降速幅度 |
