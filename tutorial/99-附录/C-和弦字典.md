# 附录 C　和弦字典

> 本字典收录 **12 个根音 × 26 种和弦类型**的组成音与右手推荐声位，**供查阅**。
> **本附录不引入任何新的命题、规则或判据**（第 5-3 章本章小结"全书正文的终点"）：和弦类型与组成音取自 [0-2 §3.1](../00-导读/0-2-记号与术语约定.md#31-常用符号总表以-c-为根音)，声位取自正文各讲；**正文未单列声位的一类（变化属和弦）另有说明**（§一 注 ③）。

**阅读约定**

| | 约定 | 依据 |
| --- | --- | --- |
| **音名与和弦符号** | 纯文本写法（`#`、`b`、`##`、`bb`）；大七写 `maj7`、半减七写 `m7b5`、减七写 `dim7`、小三写 `m` | 0-2 §1.3、§3.1 |
| **组成音的拼写** | **按三度叠置取名**：每个和弦音用"根音字母向上数"得到的字母，因而会出现 `Fb`、`Cb`、`Bbb` 等拼法（例如 `Dbm` = Db Fb Ab） | 0-2 §1.4"服从和弦构造" |
| **根音的取名** | 12 个根音取 C、Db、D、Eb、E、F、F#、G、Ab、A、Bb、B；**等音根音**（C#、D#、Gb、G#、A#）的和弦，其组成音与本表对应根音**同音而异名**，须按上一条重新拼写 | 0-2 §1.4 |
| **括号** | 组成音中带括号者**可省略**（`11` 的三音、`13` 的五音与九音） | 0-2 §3.1 |
| **左手** | 一律弹**根音**，取 **C2–B2** 之间的那一个 | 第 74 讲七步移调法第 7 步；规则 109-L |
| **右手** | 按下表"右手推荐声位"的结构**由低到高**排列；每个音取其前一音**上方最近**的位置 | 正文各讲（见下表"出处"） |
| **音高** | 科学音高记号（SPN），C4 为中央 C | 0-2 §1.2 |

>
> **注 ②（属十一和弦省三音）**：由命题 119-1，属七和弦上的 11 在三音上方半音，是回避音；**0-2 §3.1 以括号标出 `C11` 的三音可省**。**保留 11 时省去三音**，右手即为 7–9–11，与命题 125-2（`V7sus4` 就是 `iim7/V`）所述的排列同类。
>
> **注 ③（变化属和弦）**：**正文没有为变化属和弦单列声位。** 本表的排列是**本附录为列表而采用的写法**：以该变化张力音替换第 109 讲甲形态（3–7–9）中的九音，并置于七音之上。**它不是正文的规定**；使用前须按判据 119-A、规则 119-T 与规则 119-R（张力音随解决方向选取）核对。
